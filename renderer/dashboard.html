How it works

A Pomodoro companion for long desktop sessions, built on Noodle.

  • 1
    A card slides in. It floats above other windows but never takes keyboard focus.
  • 2
    Start the timer. Follow the move for the set length, or take the idea and run with it.
  • 3
    Come back fresher. Eyes, water, breath, movement. Rotate through what you need.

Not medical advice. Stop if anything hurts.
